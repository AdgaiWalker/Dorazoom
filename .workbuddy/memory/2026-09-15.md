### 已修 2：商店产物的隐私提示根本无法本地化（打包缺陷）

实测归档 `.build/DoraZoom-1.0.0-4.0.1-universal.xcarchive`：app 根 `Contents/Resources` 只有 icns/png + `ZoomItMac_ZoomItMacCore.bundle`，**10 个 lproj 全在嵌套 bundle 里**。

原因：商店通道走 `xcodebuild -project AppStore/DoraZoomStore.xcodeproj archive`，核心模块是 SwiftPM product，资源必然嵌成嵌套 bundle；而开发通道 `build-app.sh` 会把资源**扁平化**到 app 根（脚本内有注释解释 codesign 不能有嵌套 bundle 在 app 根）。

后果：系统只在 **app 自身**的 `<lang>.lproj/InfoPlist.strings` 里解析 `NSCameraUsageDescription`/`NSMicrophoneUsageDescription`，不进嵌套 bundle → **商店包 TCC 弹窗永远英文**（界面倒是正常，因为 `AppLocalization` 会主动扫描 `.bundle`）。

修法：给商店工程加 `Copy privacy strings` 脚本阶段（ID `...019`，与 `Generate app icon` 同模式，`alwaysOutOfDate = 1`，签名前写入 `<lang>.lproj/InfoPlist.strings`），并把 10 种语言加进 `knownRegions`（原为 `en`/`Base`）。

**验证方式（本机无签名身份，做不了完整归档）**：
`xcodebuild -project AppStore/DoraZoomStore.xcodeproj -scheme DoraZoomStore -configuration Release -derivedDataPath .build/DoraZoomStoreVerify build CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO`
→ BUILD SUCCEEDED，产物 app 根出现 10 个 `.lproj`，中文隐私文案正确。验证目录已删。

### 最严重的发现：`DORAZOOM_APP_STORE` 从来没作用到 SwiftPM 包目标

构建**真实商店目标**后 `nm` 检查产物：`DemoTypeController` 有 **203** 个符号、`SystemPasteCompatibilityEventTap` 19、`ControlVPasteHotkeyService` 37 —— 全都在。

**根因**：该条件只写在 `AppStore/DoraZoomStore.xcodeproj/project.pbxproj` 的 DoraZoomStore **那一个 target** 的 build settings 上，而所有依赖它的代码都在 SwiftPM 包 `ZoomItMacCore` 内。**Xcode 不把宿主 app target 的 `SWIFT_ACTIVE_COMPILATION_CONDITIONS` 转发给包目标。** 实测把它提到**项目级**（PBXProject 的 Debug/Release）也无效，符号数不变。

推论：此前所有「XX 已在商店版编译掉」的说法（模拟粘贴、快捷键兜底）**都是空头支票**。

**修法**：`Package.swift` 顶部 `import Foundation`，读 `ProcessInfo.processInfo.environment["DORAZOOM_APP_STORE"] == "1"` → `isStoreBuild`；为 true 时给 `ZoomItMacCore` 加 `.define("DORAZOOM_APP_STORE")`，并把 `PasteTapBridge` 从依赖图摘掉。

**验证闸门**：新增 `Scripts/verify-store-build.sh`（可执行），用 `nm` 断言产物**不存在** `DemoTypeController` / `AppController.startDemoType` / `SystemPasteCompatibilityEventTap` / `ControlVPasteHotkeyService`，同时断言 `AppDelegate` / `ModeCoordinator` **存在**（防把空产物判通过）。`build-app-store.sh` 现在 `export DORAZOOM_APP_STORE=1`、用独立 `DERIVED_DATA`，并在 codesign 后、`exportArchive` 前调用它，**不通过就不导出**。
