### 2.4 描述

```text
让重要之处，一眼就被看见。

DoraZoom 是为 Mac 创作者打造的原生 macOS 注意力引导工具。讲解想法、演示作品或远程协作时，你可以放大任意画面，直接圈画，并捕获对方真正需要的上下文，无需离开当前工作流。

核心工具
• 使用静态缩放或实时缩放，把视线带到重点。
• 通过画笔、形状、箭头、文字、高亮、编号、模糊和实色遮挡进行标注。
• 将区域或窗口截图复制到剪贴板或保存为文件，并用 OCR 提取可见文字。
• 录制显示器、区域或窗口；可选麦克风、系统声音、摄像头画中画，并支持暂停和继续。
• 为超出一屏的网页和对话生成滚动长截图。
• 使用 DemoType、白板、黑板和休息计时器，让现场讲解更有结构。

适合
• 教程创作者、教育者、演讲者和主播。
• 一起评审作品的设计师、开发者和产品团队。
• 需要向同伴或现有 AI 工具分享清晰视觉上下文的创作者。

DoraZoom 不宣称内置 AI 或云端推理。捕获内容与权限选择始终由你控制。

使用条款：TBD
```

- App 跟随 macOS 的单 App / 系统语言，不增加应用内语言开关。
- 权限弹窗跟随 macOS 语言，并读取此 locale 的 `InfoPlist.strings`。
- 使用简体中文冷启动后，验证 App 名称、状态菜单、设置、截图 / OCR、录屏、长截图和 DemoType。
- **发布阻断项：**提交 App Store 前，必须把两个 `TBD` 替换为审核通过且可公开访问的链接。
