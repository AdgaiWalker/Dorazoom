### 2.4 Description

```text
중요한 곳으로 시선을 자연스럽게 이끄세요.

DoraZoom은 아이디어를 설명하고 작업을 시연하며 시각적으로 협업하는 Mac 크리에이터를 위한 네이티브 macOS 도구입니다. 어떤 화면이든 확대하고 바로 그려서, 작업 흐름을 끊지 않은 채 상대에게 필요한 맥락을 전달할 수 있습니다.

핵심 도구
• 정지 화면 확대와 실시간 확대로 보여 줄 곳에 시선을 모읍니다.
• 펜, 도형, 화살표, 텍스트, 형광펜, 번호 마커, 흐림, 불투명 가리기로 주석을 더합니다.
• 영역이나 윈도우를 클립보드 또는 파일로 캡처하고 OCR로 보이는 텍스트를 추출합니다.
• 디스플레이, 영역, 윈도우를 녹화합니다. 마이크, 시스템 오디오, 카메라 화면 속 화면, 일시 정지/재개를 선택할 수 있습니다.
• 한 화면에 들어오지 않는 페이지와 대화를 스크롤 파노라마로 저장합니다.
• DemoType, 화이트보드, 블랙보드, 휴식 타이머로 실시간 설명의 흐름을 구성합니다.

추천 대상
• 튜토리얼 제작자, 교육자, 발표자, 스트리머.
• 함께 작업물을 검토하는 디자이너, 개발자, 제품 팀.
• 사람이나 평소 쓰는 AI 도구에 명확한 시각적 맥락을 전달하려는 크리에이터.

DoraZoom에는 내장 AI나 클라우드 추론 기능이 없습니다. 캡처할 내용과 권한은 언제나 사용자가 선택합니다.

개인정보 처리방침: https://dorazoom.iwalk.pro/privacy/
이용 약관: https://dorazoom.iwalk.pro/terms/
```

## 6. 런타임 및 출시 확인

- App은 macOS의 App별/시스템 언어를 따르며 App 내부 언어 전환을 추가하지 않습니다.
- 권한 대화상자는 macOS 언어를 따르고 이 locale의 `InfoPlist.strings`를 읽습니다.
- 한국어로 콜드 런치한 뒤 App 이름, 상태 메뉴, 설정, 캡처/OCR, 녹화, 파노라마, DemoType을 확인합니다.
- **출시 차단 항목:** App Store 제출 전에 두 the public legal pages를 승인된 공개 URL로 교체해야 합니다.
