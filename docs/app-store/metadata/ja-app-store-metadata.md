### 2.4 Description

```text
大切な場所へ、自然に視線を導きます。

DoraZoom は、Mac クリエイターの説明と共同作業を支えるネイティブ macOS ツールです。アイデアの説明、作品のデモ、リモートでのレビュー中に、あらゆる画面を拡大して直接描き込み、必要な文脈を作業の流れを止めずに共有できます。

主なツール
• 静止ズームとライブズームで、見てほしい場所を示します。
• ペン、図形、矢印、テキスト、蛍光ペン、番号付きマーカー、ぼかし、塗りつぶしで注釈できます。
• 範囲やウインドウをクリップボードまたはファイルに取り込み、OCR で表示中の文字を抽出できます。
• ディスプレイ、範囲、ウインドウを収録。マイク、システム音声、カメラのピクチャ・イン・ピクチャ、停止／再開を選べます。
• 1 画面に収まらないページや会話を、スクロールするパノラマ画像として保存できます。
• DemoType、ホワイトボード、ブラックボード、休憩タイマーで、ライブ説明の流れを整えます。

こんな方に
• チュートリアル制作者、教育者、プレゼンター、配信者。
• 一緒に制作物をレビューするデザイナー、開発者、プロダクトチーム。
• 人や普段使う AI ツールに、明確な視覚的文脈を渡したいクリエイター。

DoraZoom は AI 内蔵やクラウド推論をうたう製品ではありません。取り込む内容と権限は、常にユーザーが選択できます。

プライバシーポリシー：TBD
利用規約：TBD
```

## 6. 実行時とリリース前の確認

- App は macOS の App ごと／システムの言語に従い、App 内の言語切り替えは追加しません。
- 権限ダイアログは macOS の言語に従い、この locale の `InfoPlist.strings` を読み込みます。
- 日本語でコールド起動し、App 名、ステータスメニュー、設定、取り込み／OCR、収録、パノラマ、DemoType を確認します。
- **リリースを妨げる項目：**App Store への提出前に、2 つの `TBD` を承認済みの公開 URL に置き換える必要があります。
