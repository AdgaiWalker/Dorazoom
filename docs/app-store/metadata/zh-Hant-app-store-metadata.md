### 2.4 描述

```text
讓重要之處，一眼就被看見。

DoraZoom 是為 Mac 創作者打造的原生 macOS 注意力引導工具。講解想法、展示作品或遠端協作時，你可以放大任何畫面，直接圈畫，並擷取對方真正需要的視覺脈絡，不必離開目前的工作流程。

核心工具
• 使用靜態縮放或即時縮放，把視線帶到重點。
• 透過畫筆、形狀、箭頭、文字、螢光標記、編號、模糊和實色遮蔽進行標註。
• 將區域或視窗截圖複製到剪貼板或儲存成檔案，並用 OCR 擷取可見文字。
• 錄製顯示器、區域或視窗；可選麥克風、系統聲音、相機子母畫面，並支援暫停與繼續。
• 為超出一個畫面的網頁與對話製作捲動長截圖。
• 使用 DemoType、白板、黑板和休息計時器，讓現場講解更有結構。

適合
• 教學創作者、教育工作者、簡報者和直播主。
• 一起檢視作品的設計師、開發者與產品團隊。
• 需要向夥伴或現有 AI 工具分享清楚視覺脈絡的創作者。

DoraZoom 不宣稱內建 AI 或雲端推論。擷取內容與權限選擇始終由你控制。

隱私權政策：TBD
使用條款：TBD
```
