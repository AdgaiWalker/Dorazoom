# DoraZoom Mac App Store screenshots

The six PNGs in `zh-Hans/` are 1440×900 captures from the DoraZoom Store target, Release version 1.0.0 build 4, running locally on macOS. They cover the real app's zoom, shortcuts, capture/draw, recording, permissions, and advanced settings surfaces.

They are prepared for the App Store Connect screenshot slot. Before upload, re-capture from the signed Archive/TestFlight build if the final signing build changes the UI; do not use the website audit images as App Store screenshots.
